## Shared Contracts

### CSV

Exact header:

```text
nama;kategori;BK;abu;lemak;serat;PK;BETN;TDN;ME;harga;Ca;P
```

Numeric precision on export:

- `BK`, `abu`, `lemak`, `serat`, `PK`, `BETN`, `TDN`, `ME`, `Ca`, `P`: 2 decimal places.
- `harga`: 0 decimal places.
- Decimal separator `,`; thousands separator `.`.
- UTF-8; delimiter `;`; no `id` or `isActive` columns.

### Import

```dart
Future<HasilImportBahanPakan> replaceFromCsv(String csv)
```

Behavior:

- Trim and lowercase names for matching.
- Last duplicate normalized name in input wins.
- Existing matching name preserves ID.
- New name gets ID above current maximum.
- Missing existing names are permanently removed.
- Any validation error aborts before persistence.
- Persistence uses one controlled replacement operation; failure restores prior in-memory/Hive dataset and returns failure.

### Calculation state

```dart
enum StatusPerhitungan { belumDihitung, berhasil, gagal }
```

Input mutation sets `belumDihitung`; successful calculation sets `berhasil`; validation/calculation exception sets `gagal` with a user-facing message.

- [ ] **Step 5: Implement controlled replacement.**

Algorithm:

```text
oldData = copy current data
parsed = parse and validate full CSV
replacement = match names to oldData, preserve IDs, assign new IDs
counts = calculate added/updated/deleted in memory
try:
  persist replacement once through local source
  replace repository memory with replacement
catch:
  restore previous Hive dataset through local source
  restore repository memory to oldData
  rethrow controlled import failure
return counts
```

Do not clear Hive before validation. If the underlying Hive operation is clear-then-add, wrap it so the old list is retained and restore is attempted when add fails.
